# Image provenance

The PNG images in this directory are original photorealistic illustrations generated with OpenAI image generation for the Aurix Travels website in this task, 3 November 2026. The hero was generated with the user-supplied approved light-themed design reference as composition guidance, with all interface elements removed and new original scenery rendered. Destination images were generated independently from text descriptions.

These are illustrative images, not documentary photographs or promised package/hotel views. No destination photograph was copied from the reference websites. Public-facing content must not suggest a depicted hotel, experience, or itinerary is bookable without verification.

All business details and image choices require owner review before launch. Fonts retain separate SIL OFL licences in `public/fonts`. The temporary typographic/plane brand mark is not a verified official company logo.
